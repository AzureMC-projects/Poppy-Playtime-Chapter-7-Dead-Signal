# Contributing

Thanks for helping with **Poppy Playtime: Chapter 7 — Dead Signal**.

## Development rules

- Use Java 25.
- Keep gameplay code under `src/main/java/dev/azuremc/deadsignal/`.
- Prefer small, focused classes and clear names.
- Do not commit copyrighted game assets, ripped models, leaked material, or audio without redistribution rights.
- Keep the project buildable on every pull request.
- Add or update documentation when a feature changes player-facing behaviour.

## Branches

Use focused branches such as:

- `feature/grabpack-prototype`
- `feature/sector-07-room`
- `fix/menu-input`

## Commits

Prefer conventional, descriptive commit messages:

- `feat: add interactable power panel`
- `fix: prevent menu input leaking into gameplay`
- `docs: update build instructions`
- `chore: update CI`

## Pull requests

A pull request should explain:

1. What changed.
2. How it was tested.
3. Whether assets or dependencies were added.
4. Any known limitations.

## Fan-project policy

This is an unofficial fan project. Contributions must respect the rights of the original IP holders and the licenses of any third-party dependencies or assets.
